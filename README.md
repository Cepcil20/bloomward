BLOOMWARD — Night Garden Defense: an original canvas tower-defense game set in a moonlit garden. Three flower towers (Sunflower, Frost Fern, Thorn Cannon) defend against beetles, wasps and brutes across 12 waves, with a seeds economy, 10 hearts, and synthesized WebAudio sounds.

## Run it

```sh
npx serve game
```
